# 🧠 HMW 가상 팀원 브레인스토밍 보드

설문조사 주관식 답변에서 도출한 **HMW(How Might We) 질문**을 가상 팀원들과 함께 브레인스토밍하는 Streamlit 앱입니다.
Gemini가 서로 다른 관점을 가진 가상 팀원들의 토론을 만들어 아이디어 발산부터 실행 계획까지 이어 줍니다.
[설문조사 입체 분석 대시보드](https://github.com/Song-Wick/survey-dashboard)의 Step 8(HMW 도출) 다음 단계로 쓰기 좋게 만들었습니다.

## 브레인스토밍 모드

사이드바의 **"토론 프레임워크 선택"** 메뉴에서 세 가지 모드 중 하나를 고릅니다.

| 모드 | 진행 방식 | 이런 때 좋아요 |
|---|---|---|
| 📚 대학도서관 HMW 브레인스토밍 | 넓게 → 좁게 → 계획, 3단계로 나눠 진행하고 단계마다 사서가 직접 고름 | 도서관 서비스 개선안을 이용자 관점에서 정하고 파일럿 계획까지 세울 때 |
| 🚀 실리콘밸리식 10단계 브레인스토밍 | 한 번에 10단계 회의록 생성 (MVP, UX, 기술 구조, 성장 지표 등) | 디지털 서비스나 앱처럼 제품 관점의 아이디어가 필요할 때 |
| 👔 맥킨지/BCG식 10단계 전략 수립 | 한 번에 10단계 회의록 생성 (MECE, 2x2, BCG 매트릭스, KPI 등) | 중장기 전략이나 보고서용 논리 구조가 필요할 때 |

### 📚 대학도서관 HMW 브레인스토밍

[OpenAI Academy의 'ChatGPT로 브레인스토밍' 가이드](https://openai.com/ko-KR/academy/brainstorming/)가 제안하는 흐름(결정부터 정하기 → 제약 조건 주기 → 아이디어 내기와 평가 분리 → 실행 계획)을 따릅니다.
AI의 결과를 사람이 판단해 다듬는 초안으로 보고, 단계 사이마다 사서가 고르고 메모를 남길 수 있게 했습니다.

| 단계 | 내용 |
|---|---|
| 🎯 결정과 제약 조건 | 결정할 것, HMW 질문, 대상 이용자, 기간, 예산·인력, 성공 측정 방법, 이미 해 본 시도, 양보할 수 없는 조건, 설문 답변·공감 지도 발췌 입력 |
| 🌱 1단계 · 넓게 | 비판 없이 아이디어 15~20개 생성 (제안자, 설문 근거 표시) → 체크박스로 선택 |
| 🔎 2단계 · 좁게 | 주제별 묶음, 영향력·노력·확신·이용자 체감·형평성 점수(1~5점), 빠른 성과/기반 작업 구분, 영향력 × 노력 2x2, 개선 제안, 빈틈 확인, "하나만 고른다면" 추천 |
| 🗺️ 3단계 · 계획 | 한 학기 파일럿 실행 계획, 성과 지표, 보수적·균형적·진보적 세 가지 경로, 이해관계자 맵, 시작·중단·계속·재검토할 것 |

**가상 팀원:** 🧭 퍼실리테이터, 🎓 학부생, 🔬 대학원생·연구자, 👩‍🏫 교수, 📚 주제전문사서, 🖥️ 디지털·시스템 사서, 🏛️ 행정·예산 담당, ♿ 접근성·포용 담당

- 설문 발췌를 붙여 넣으면 아이디어의 근거로 쓰며, 발췌에 없는 인용은 만들지 않도록 지시합니다.
- 2x2 분류는 AI가 매긴 점수로 코드가 직접 나눕니다. 4점 이상을 '큼'으로 보며(3점은 보통), `brainstorming.py` 위쪽의 `MATRIX_HIGH_SCORE`에서 바꿀 수 있습니다.
- 3단계 계획에 들어가는 가상 팀원의 발언에는 실제 설문 인용과 구분되도록 `🎓 학부생 (가상 의견): "..."`처럼 표시가 붙습니다. 모델이 표시를 빠뜨려도 코드가 자동으로 붙입니다.
- 앞 단계를 다시 실행하면 뒤 단계 결과와 선택이 초기화됩니다.

### 🚀 실리콘밸리식 · 👔 맥킨지/BCG식

주제 한 줄을 입력하면 10단계로 깊어지는 회의록을 한 번에 만듭니다. 결과는 전체 보기 또는 레벨별 탭으로 볼 수 있습니다.

- **실리콘밸리식:** 창업자, PM, 엔지니어, 디자이너, 투자자, 주니어·시니어 사서
- **맥킨지/BCG식:** 파트너, 프로젝트 매니저, 어소시에이트, 비주얼 스페셜리스트, 외부 자문위원, 주니어·시니어 사서

모든 모드의 결과는 사이드바에서 Markdown 파일로 내려받을 수 있습니다.

## 설치 및 실행

Python 3.10 이상을 권장합니다.

```bash
pip install streamlit -r requirements.txt
```

```bash
streamlit run brainstorming.py
```

### Gemini API 키 설정

키를 Secrets에 등록해 두면 사이드바의 **🔑 API 설정**에 "✅ Gemini API Key 자동 적용됨"이 표시되고 따로 입력할 필요가 없습니다.

- **Streamlit Community Cloud에 배포한 경우:** 앱의 **Settings → Secrets**에 아래 내용을 넣으세요.
- **내 컴퓨터에서 실행하는 경우:** 프로젝트 폴더에 `.streamlit/secrets.toml` 파일을 만들고 같은 내용을 넣으세요. 이 파일은 `.gitignore`에 포함되어 있어 저장소에 올라가지 않습니다.

```toml
GEMINI_API_KEY = "여기에_API_키"
```

Secrets에 키가 없으면 사이드바에 입력란이 나타납니다. 입력한 키는 브라우저 세션 동안 유지되며 모든 모드에서 사용됩니다.

모든 모드는 **Gemini 2.5 Flash**(`gemini-2.5-flash`)를 사용합니다.
